# Agent API

Shelf exposes a JSON REST API for agents and other HTTP clients. Protected requests use a user-owned API key as a bearer credential. The key can manage its owner's boards and create apps in the shared library, but can edit or delete only apps its owner created. Keys have no separate scopes or read-only mode.

## Resource contract

All IDs below are stable database IDs. A board response also includes its public `nanoid` and `/board/<nanoid>` URL. Successful writes return the resulting resource, except deletes, which return `204 No Content`. Lists have a stable order: boards by creation time then ID, apps by name then ID, categories by saved position, and assignments in display group and saved order. Dates are ISO 8601 strings. App responses expose the owner ID, saved icon source, slug or custom URL, local icon URL, description, and recorded liveness state.

| Method                     | Path                                        | Behavior                                                                                                                                                                                                     |
| -------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `GET` / `POST`             | `/boards`                                   | List the key owner's boards with categories and assignments / create a board with `name`. The first board becomes default.                                                                                   |
| `GET` / `PATCH` / `DELETE` | `/boards/{boardId}`                         | Read one owned board / rename with `name` / delete it. Deleting the default selects the oldest remaining owned board.                                                                                        |
| `PUT`                      | `/boards/{boardId}/default`                 | Set an owned board as the user's default.                                                                                                                                                                    |
| `GET` / `POST`             | `/apps`                                     | List all shared apps / create one owned by the key's user.                                                                                                                                                   |
| `GET` / `PUT` / `DELETE`   | `/apps/{appId}`                             | Read one shared app / replace its editable fields if owned / delete it and all board assignments if owned.                                                                                                   |
| `POST`                     | `/boards/{boardId}/categories`              | Create a category with `title` and optional `description`.                                                                                                                                                   |
| `PATCH` / `DELETE`         | `/boards/{boardId}/categories/{categoryId}` | Edit title and/or description / delete the category, moving its apps to the end of uncategorized apps.                                                                                                       |
| `PUT`                      | `/boards/{boardId}/categories/order`        | Set category order with `categoryIds`, a complete permutation of that board's category IDs.                                                                                                                  |
| `POST`                     | `/boards/{boardId}/apps`                    | Assign an existing shared app with `appId` and optional `categoryId`; omitted or `null` means uncategorized.                                                                                                 |
| `PATCH` / `DELETE`         | `/boards/{boardId}/apps/{appId}`            | Set `categoryId` to another category on this board or `null` / remove the assignment without deleting the shared app. Changing category appends the app to its new group.                                    |
| `PUT`                      | `/boards/{boardId}/apps/order`              | Set assignment order with `appIds`, a complete permutation of assigned app IDs in display group order: uncategorized first, then each category in its saved order. Category membership is unchanged.         |
| `GET`                      | `/icons/search?q={query}&limit={limit}`     | Search published Dashboard Icons slugs and aliases. Return matching `slug`, `aliases`, and remote `previewUrl` values in deterministic slug order. Query is required; default limit is 20 and maximum is 60. |

The `POST /apps` and `PUT /apps/{appId}` bodies contain the complete editable app fields: `name`, `description` (empty string allowed), `url`, and exactly one icon choice. A Dashboard Icons choice is `{ "iconSource": "dashboard", "iconSlug": "..." }`; a custom PNG choice is `{ "iconSource": "url", "iconUrl": "https://..." }`. The app response uses `customIconUrl` for a saved URL and includes `iconHash` when applicable. `PUT` requires all editable fields, even when only one changes, so switching icon sources is explicit. Server-managed IDs, assignments, status, and timestamps cannot be set through these bodies.

All existing app, board, and category limits apply. App and custom icon URLs accept HTTP(S), including private household hosts. Custom icons must be PNG images no larger than 5 MB. If icon validation or retrieval fails, the app is unchanged. Icon search returns remote preview URLs without creating saved icons.

## Responses and failures

- Every protected request without a valid, active bearer key returns `401` with `{ "error": { "code": "UNAUTHORIZED", "message": "..." } }`. Missing resources and boards owned by someone else both return `404`.
- Invalid JSON, missing fields, invalid URLs, invalid category membership, and incomplete or invalid order lists return `400`, with field-level details where applicable. Editing or deleting another user's app returns `403`. A duplicate board assignment, case-insensitive duplicate category title, or app URL already used by another app returns `409`. A remote icon catalogue or PNG fetch failure returns `502`; the app remains unchanged. Unexpected failures return `500` without exposing secrets or internal details.
- Create operations return `201`; reads and edits return `200`; deletes return `204`. Responses use `application/json` except `204`. The OpenAPI document defines concrete schemas, status codes, bearer security, and examples for every operation.
- Browser sessions do not grant access to REST data operations. Public board pages remain separate from this API.
